## Smallest detectable held-out improvement (alpha 0.05 two-sided, power 80%)

Baseline from the first dev folder (277 dev cases): top-1 = 41.2%, wrong auto-commit = 11.6%. Held-out n = 82.

Unpaired two-proportion z-test (two independent samples of n each): power = 1 - Φ((z_α/2·sqrt(2·p̄(1-p̄)/n) - δ) / sqrt((p0(1-p0) + p1(1-p1))/n)), p̄ = (p0+p1)/2, p1 = p0+δ; δ solved by bisection for power = 0.8.
Paired McNemar test: with discordant fraction D = 2δ + 0.10 and net gain δ, required n = (z_α/2·sqrt(D) + z_β·sqrt(D - δ²))² / δ²; δ solved by bisection for n = held-out n (δ is the change in rate = (b - c)/n).

| top-1 | 41.2% | 21.7% | 22.7% |
| wrong auto-commit | 11.6% | 10.5% | 22.7% |
